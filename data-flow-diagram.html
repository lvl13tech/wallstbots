⚡ Core Scaling Formula
entry_cost = len(holdings) × $1,000
ratio = tracker.total / starting_capital
total_value = entry_cost × ratio
gain_loss = total_value − entry_cost
gain_loss_pct = gain_loss / entry_cost × 100
day_pct = tracker.day_pct ← capital-neutral
day_pnl = total_value × (day_pct / 100)

⚠️ Data Integrity Rules — Read Before Making Any Change
1 Single source of truth for member dollar values is bot_fund_state. Written exclusively by refresh_portfolios.py. Never hardcode or compute member dollar values in the frontend — always read from this table.
2 day_pct is capital-neutral — it is the same number on the public homepage, bot-detail leaderboard, portfolio-fund stat card, and dashboard best return. If you change how day_pct is calculated in refresh_portfolios.py, all 4 locations update automatically. If you change it only in the frontend on one page, the pages will diverge.
3 Dollar values differ by scale. Public pages show platform-scale dollars (tracker). Members pages show member-scale dollars (bot_fund_state). Never compare or cross-display these dollar amounts. Percentages (day_pct, gain_loss_pct, position pnl_pct) are the same on both sides.
4 Starting capital hardcoded per platform: wallstbots=$55,000, lvl13=$49,000, bitbot13=$50,000. This value appears in refresh_portfolios.py and as fallback in app.js fundCard(). If it changes, update both places.
5 entry_cost = len(holdings) × $1,000 always. It is never stored as a variable dependent on anything else. If a member adds or removes a holding, entry_cost changes and refresh_portfolios.py must re-run to recalculate all derived values.
6 BOT13 holding_cash must always be true after session end, regardless of the trading decision made that day. Formula: holding_cash = decision in ("CASH","HOLD") OR session_ended. This flag controls the "End of trading — holding cash" message on portfolio-fund and suppresses positions on the dashboard banner.
7 The leaderboard (leaderboard.html) ranks by gain_loss_pct (all-time). The bot-detail leaderboard strip shows day_pct (today). These are intentionally different and serve different purposes. Do not conflate them.
8 All timezone-sensitive operations must use ET (America/New_York). This applies to session open/close detection, snapshot_date, and holding_cash determination in refresh_portfolios.py.
9 Public fund pages (homepage) only show Bot13, Oracle, Wizard. Equalizer and Titan are members-only. If you add a public-facing view for baselines, ensure their tracker data is included in /public/tracker/state.
10 Any frontend fallback value must use the same formula as the backend. E.g. the dashboard's dayPnl fallback is total - day_open. If the backend formula changes, the frontend fallback must be updated to match, or removed.
